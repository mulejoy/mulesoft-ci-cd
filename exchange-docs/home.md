# mulesoft-ci-cd

A reference MuleSoft application demonstrating a complete CI/CD pipeline for CloudHub 2.0 using GitHub Actions and the Mule Maven Plugin.

## Overview

This project provides a minimal but production-ready Mule 4 application template with:

- A simple HTTP listener (`GET /hello`) as the deployable artifact
- Structured Log4j2 logging for both runtime and test environments
- Maven-based build and deployment via the Mule Maven Plugin
- GitHub Actions workflow for automated build and multi-environment deployment
